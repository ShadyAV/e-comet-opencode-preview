# e-Comet для OpenCode: экспериментальный npm-пакет

Это экспериментальный пакет для проверки установки и обновления через npm.
Для проверки используется OpenCode 2.0.22; пакет пока не является официальным
релизом e-Comet. Установка без Git ещё проверяется, успешная проверка пока
не заявлена. Новая авторизация OAuth не проверялась.

Добавьте пакет в файл `opencode.json` вашего проекта:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": ["-e-comet", "@avshady/e-comet-opencode@preview"],
  "snapshots": false
}
```

Откройте проект в OpenCode. Настройте провайдер модели средствами OpenCode,
если он ещё не подключён, затем попросите агента подключить e-Comet и следуйте
инструкции авторизации. Для работы с Wildberries нужны расширение e-Comet в Chrome
и открытая вкладка Wildberries.

Начните вводить `/ecomet-version` в чате: список команд показывает версию
исполняемого пакета в описании команды. Вызов команды добавляет диагностическую
запись в очередь сеанса без запуска модели или бизнес-инструментов e-Comet.
Запись попадёт в историю при следующем обычном обращении к модели.

Для обновления используйте штатную CLI-команду OpenCode в каталоге проекта:

```sh
opencode plugin update '@avshady/e-comet-opencode@preview'
```

После обновления проверьте версию в описании `/ecomet-version` в списке команд.
Команда `/ecomet-update` пока не реализована. Пакет не содержит установочных
скриптов или внешних зависимостей; установку выполняет OpenCode.
