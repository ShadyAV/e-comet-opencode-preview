# e-Comet для OpenCode: экспериментальный npm-пакет

Это экспериментальный пакет для проверки установки и обновления через npm.
Пакет пока не является официальным релизом e-Comet. На Windows с OpenCode 2.0.22
установка из npm проверена без внешних Git, Node.js и npm. Обновление через команду
плагина ещё проверяется. Новая авторизация OAuth не проверялась.

Добавьте пакет в файл `opencode.json` вашего проекта:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": ["-e-comet", "@avshady/e-comet-opencode@preview"],
  "snapshots": false
}
```

Откройте проект в OpenCode. Настройте провайдер модели средствами OpenCode,
если он ещё не подключён, затем попросите агента подключить e-Comet и следуйте
инструкции авторизации. Для работы с Wildberries нужны расширение e-Comet в Chrome
и открытая вкладка Wildberries.

Введите `/ecomet-update` в чате: команда проверит обновления и при необходимости
обновит пакет средствами OpenCode. Проверка выполняется без обращения к модели.
Итог показывает в чате выбранная вами модель OpenCode.
Пакет не содержит установочных скриптов или внешних зависимостей;
установку выполняет OpenCode.
