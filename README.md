# e-Comet для OpenCode: экспериментальный npm-пакет

Это экспериментальный пакет для проверки установки и обновления через npm.
Пакет пока не является официальным релизом e-Comet. На Windows с OpenCode 2.0.22
установка из npm проверена без внешних Git, Node.js и npm. Обновление через команду
плагина ещё проверяется. Новая авторизация OAuth не проверялась.

Добавьте пакет в файл `opencode.json` вашего проекта:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": ["-e-comet", "@avshady/e-comet-opencode@preview"],
  "snapshots": false
}
```

Откройте проект в OpenCode и введите `/ecomet-connect` в поле нового чата.
Команда откроет обычный браузер: войдите в аккаунт e-Comet и дождитесь результата
подключения в OpenCode. Запуск авторизации не требует модели или API-ключа.
Для работы с Wildberries нужны расширение e-Comet в Chrome и открытая вкладка Wildberries.

Для следующих обновлений введите `/ecomet-update`: команда проверит обновления
и при необходимости обновит пакет средствами OpenCode. Проверка выполняется
без обращения к модели. Итоги обеих команд сохраняются в OpenCode;
выбранная вами модель показывает готовый результат в чате.
Пакет не содержит установочных скриптов или внешних зависимостей;
установку выполняет OpenCode.
